# 一点｜工作与学习的收藏回看工具

> 重要的，不只见一次。

在工作和学习中看到值得再见的网页或选段，第 1 天先收下；一点在第 2、7、30 天重新把它带到面前，宠物也随每次回来长一点。

## 在线体验

创空间提供可拖动宠物、收藏、四阶段成长和第 1、2、7、30 天节奏演示。真实跨网页能力由下载后的 Chrome 和 Edge 电脑浏览器扩展提供。

## 隐私

扩展不读取未选择的网页正文，不发送产品数据到网络，不要求登录。它只在浏览器本地保存标题、网址、用户主动选择的文本、进度和回来时间。

## 当前能力

- 在普通网页中唤出、拖动和巡游；
- 收下后进度变为 1/4，并明确提示第一次回看时间；
- 共 4 步：第 1 天收下 1 次，在第 2、7、30 天回看 3 次；
- 一次只带回一条到期收藏；
- 收藏库支持搜索、归档与温和统计，完成的内容可以随时带回；
- 默认 22:00–08:00 免打扰，多条到期时每天最多一条摘要通知；
- 可导出 JSON 备份或带来源、选段与相见足迹的 Markdown；
- 侧边栏会先展示当初保存的选段，帮助想起为什么收下；
- 短时间内重复点击只确认“已经记下”；隔一段时间再次收下同一页时记为“途中偶遇”，不重置原来的回看计划；
- 本地查看相见次数与足迹，打开、删除、导入和导出收藏；
- 完成一轮后，可以从 1/4 重新开始。

官网手动版和 Microsoft Edge 商店版均为 `1.3.4`，功能一致。2026-10-01 已核对商店审核通过并上线。Edge 用户可从商店安装及更新；解压版升级时先导出备份，再在原安装文件夹替换文件并刷新扩展。换安装方式时，两份扩展的本地收藏需通过备份迁移。

当前先把 Chrome 和 Edge 浏览器闭环做稳；下一步验证本地文档、笔记和项目资料的收藏与回来，不提前建设通用多平台框架。
