2026-09-29 官网当前版本

1.3.2 · 收藏与升级更稳

旧收藏出现异常，也能继续使用。

  • 无法识别的旧记录会留在浏览器本地，并随 JSON 备份导出；正常收藏仍能查看和回看。
  • 官网说明了解压版在原文件夹更新的方法，避免重复加载后收藏分散、快捷键冲突。
  • 发布前核对源码、版本号和安装包，并补上异常数据与升级流程的检查。
2026-09-07 历史版本

1.3.1 · 修好了归档删除

归档里的记录，现在也能删掉了。

  • 修复了「已归档」里的记录无法删除的问题：删除现在会同时从收藏库和归档中移除。
  • 删除不存在的记录时会明确提示，不再假装成功。
  • 数据层加固：一条 URL 无效的旧记录不再让整个收藏库空白。
  • 归档数据也纳入治理：读取、导入和浏览器启动时都会规范化归档记录，避免重复和损坏。
  • 侧边栏和宠物注入对无效 URL 做了容错，遇到不认识的页面不会崩溃。
  • 宠物卡片操作失败时会明确报错，不再静默返回空状态。
  • 宠物被「先躲一躲」隐藏后会暂停漫游，不再在后台浪费 CPU。
  • 本地存储写入失败时会给出提示，同时提高了扩展可用的本地存储空间。
  • 收藏库搜索加了 150ms 防抖，大量记录时输入更流畅。
  • 回看节奏、本地存储和最小权限没有变；解压版升级需沿用原安装文件夹。
2026-08-19 历史版本

1.3.0 · 更温柔的回看

没读完也没关系，一点不记账。

  • 收藏库支持导出 Markdown：每条记录一段，带选段和相见足迹，可直接放进 Obsidian 或任何笔记库。
  • 到期通知更克制：多条到期时每天只发一条计数提醒，点一下进收藏库；只有一条时才直达原网页。
  • 回看前先见选段：侧边栏会先展示当初收下的那一段文字，帮你想起它为什么重要。
  • 第一次打开收藏库时，有一份三十秒的上手指引；空空的库不再只是一句冷冰冰的提示。
  • 官网和收藏库都写明了：这里不是待办清单，忘了也没关系。
  • 回看节奏、本地存储和最小权限仍然没有变；旧版本平滑升级。
2026-08-18 官网可下载

1.2.0 · 收藏库、免打扰、统计与侧边栏

收下的东西，现在可以更安静地找回来。

  • 收藏库新增搜索和状态筛选；完成的内容可以一键归档，归档随时能查看、恢复，导出备份也会带上它们。
  • 到期通知有了免打扰时段（默认 22:00–08:00，可在收藏库里改）；点击通知直接打开原网页，文案也更轻了。
  • 新增“统计”页：只数已经发生的事——收藏总数、完成次数、相见次数，没有连续天数，也没有倒计时。
  • 新增侧边栏（快捷键 Alt+Shift+Y）：随时看当前网页的收藏状态。工具栏的一点仍是主入口，侧边栏只是安静的侧窗。
  • 回看节奏、本地存储和最小权限都没有变；旧版本平滑升级，不需要迁移。
2026-08-03 官网可下载

1.0.3 · 一点说话更像一点

宠物还是那只宠物，说话和操作轻了一点。

  • 宠物卡片改成轻量对白、一个主动作和三项文字操作，不再堆叠大号按钮。
  • 卡片内不再重复出现小宠物图标；完整宠物仍会在网页上散步、拖动和成长。
  • 未收藏、到期、途中偶遇和完成状态，改用同一套更像一点的宠物口吻。
  • 宠物对白使用开源的站酷小薇体；正文和按钮继续使用清楚的系统字体，字体许可证随扩展保留。
  • 回看节奏、本地收藏数据和导入导出方式不变。
  • 官网现在可以安装为 PWA，在独立窗口中打开，并在新版本准备好后提示更新。
2026-08-02 官网可下载

1.0.2 · 把重复收藏改成途中偶遇

忘了自己收藏过，再点一次，也不会回到起点。

  • 再次收下同一网页时，不再新增重复记录，也不重置原来的回看进度。
  • 短时间内重复点击只会确认“已经记下”；隔一段时间再次遇见，才会记作“途中偶遇”，并留下时间足迹。
  • 升级后，旧的重复收藏会自动合成一条，并保留较完整的回看进度。
  • 完成 4/4 后仍想继续，可以主动重新开始一轮。
  • 已在 Edge 中验证收藏、偶遇、导入和回看流程；收藏数据仍只保存在本地。
2026-07-30 官网可下载 · Edge 审核中

1.0.1 · 说清楚四步

不再让第一次使用的人猜“1/4”是什么意思。

  • 首次打开时直接说明：每条内容共 4 步，收下 1 次，再回看 3 次。
  • 收下后显示“进度 1/4”，并明确提示第一次回看的时间。
  • 收藏页、官网演示和浏览器按钮提示使用同一套语言。
  • 本次只调整说明方式，不改变回看节奏，也不会影响已有本地收藏。
  • 1.0.1 已可从官网手动下载；Microsoft Edge 商店仍提供 1.0.0，更新正在审核。
2026-07-28 第一版

1.0.0 · 第一版

第一版，把收藏、回看和成长连成一条完整路径。

  • Microsoft Edge 商店正式上线，Edge 用户现在可以直接安装并接收后续更新。
  • 在 Chrome 和 Edge 电脑浏览器中，收下当前网页或主动选择的一段文字。
  • 第 1 天收下，第 2、7、30 天重新带回内容，每次回看让宠物长一点。
  • 到期时，工具栏图标显示待回看的数量；不弹窗，也不强制打扰。
  • 在“我的收藏”页查看回看日期和进度，也能打开原网页或删除记录。
  • 支持导入、导出备份；无需登录，记录只保存在浏览器本地。
