# 一点｜工作与学习的收藏回看工具

> 重要的，不只见一次。

每条内容共 4 步：收下 1 次，再回看 3 次。

如果一点确实帮你把一份重要内容重新带回了工作或学习，欢迎给这个开源项目一个 [Star](https://github.com/endtree-FDE/yidian)。它会帮助更多人看见这个还很小的项目。

一点把你在工作和学习中收藏的重要内容，在第 2、7、30 天重新带到面前。当前支持 Chrome 和 Edge 电脑浏览器：第 1 天收下整页或选段，进度变为 1/4；以后在第 2、7、30 天各回看一次，宠物也跟着长一点。

## 产品组成

- `extension/`：Manifest V3 浏览器扩展，当前支持 Chrome 和 Edge，负责跨网页收藏、再次带回和本地记录。
- `studio/`：ModelScope Static 创空间，负责公开互动演示、产品说明和扩展下载。
- `tests/`：调度、并发写入、注入恢复、交互、清单资源和创空间检查。

## 本地验证

```text
npm run check
```

Edge 商店与官网手动安装包均为 `1.3.4`。2026-10-01 已确认商店状态为 Live，扩展 ID 保持不变；公开商店包的代码与资源和官网包一致。ModelScope 下载包由 `extension/` 的同一份源码生成，ZIP 根目录直接包含 `manifest.json`。

解压版升级前先在“我的收藏”导出 JSON 备份，再把新文件放进原安装文件夹并刷新原扩展。换文件夹重新加载会生成另一个扩展 ID，旧收藏不会自动跟过去。

## 隐私

扩展不读取未选择的网页正文，不发送产品数据到网络，不要求登录。浏览器本地仅保存标题、网址、用户主动选择的文本、进度、回来时间和宠物设置。

## 1.3.4 已包含

- 收下整页或选段，并保存主动选择的文字上下文
- 共 4 步：第 1 天收下 1 次，在第 2、7、30 天回看 3 次，进度从 1/4 到 4/4
- 一次只带回一条到期内容，不制造新的提醒积压
- 收藏库顶部显示“今天看一条”；看过后可选“用上了”“稍后再看”“不再需要”。推迟到明天不改变进度，不再需要会收入可恢复的归档
- 网页宠物巡游、拖动与安静陪伴
- 宠物以轻量对白卡片出现；站酷小薇体只用于宠物说的话，正文和操作继续使用清楚的系统字体
- 我的收藏：总数、今天待回看、已完成回看计划
- 查看日期与进度、打开原网页、删除记录
- JSON 本地备份的导入与导出
- 收藏库搜索、完成项归档与恢复，以及 Markdown 导出
- 可选到期通知、免打扰时段与北京时间的每日摘要去重
- 侧边栏展示打开时的网页状态、下次回看时间与操作；切换网页后会停用旧页动作，另有本地回看统计
- 短时间内重复点击只确认“已经记下”；隔一段时间再次收下同一内容时记为“途中偶遇”，保留原来的回看进度；旧重复项会自动合并
- 在收藏页查看相见次数与时间足迹；完成一轮后可以重新开始
- 无需登录，记录只保存在浏览器本地
