# Review

## 通过
- 用户在十秒内能看到结果。
- 名称带功能解释，不只写“一点”。
- 没把 Skill 误写成小红书站内收藏夹。
- 没承诺宿主不一定支持的定时提醒。
- 保存位置透明，采用可读 Markdown，不建隐藏数据库。
- 笔记先讲具体困境和结果，再讲安装。
- 品牌语言保持“收下、相见、带回”，不制造逾期和打卡压力。

## 待真实验证
- 当前后台可选的场景标签。
- 安装口令在常见 Agent 中的兼容性。
- 小红书是否已向该账号开放站内小工具运行。
- 首批用户能否不经解释完成“收下一条”。

## 发布闸门
先自己安装一次并跑通“收下 → 保存 → 回看”；再上传 Skill。发布和挂载由用户本人确认执行。

## 首轮测例
1. 粘贴一段文字并说“用一点收下”：先出现完整记录卡，不先讲功能。
2. 只给无法读取的链接：不虚构正文；请用户补文字，或仅按标题与来源收下。
3. 宿主没有文件或定时能力：返回可复制记录和准确日期，不声称已保存或会自动提醒。
4. 有到期记录并说“回看一条”：一次只带回一条；用户回应“用上 / 继续留下 / 不再需要”后才更新进度。
