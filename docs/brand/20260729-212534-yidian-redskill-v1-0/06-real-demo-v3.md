# 一点 RED Skill｜真实演示 V3

## 一句话定义

“用一点回看一条”不是密码，也不是安装口令。它是安装一点以后，对 AI 发出的日常使用句：从 `一点记录.md` 中带回当前最该见的一条记录，一次只看一条，再决定“用上 / 继续留下 / 不再需要”。

## 这次演示的真实闭环

1. 昨天看到一句判断：第一版不要先追求功能完整，先让最小闭环被真实用户走通。
2. 对 AI 说：“用一点收下这段：……”
3. 到回看日，主动说：“用一点回看一条”。
4. 一点带回原句与上次判断，并问“现在它对你还有什么用？”
5. 选择“用上”，把旧判断变成今天的一个小行动。

## 两种“话”不要混淆

- 安装口令：小红书 Skill 页面自动生成，只在安装时复制一次；以“一点”页面实际内容为准。
- 日常使用句：
  - `用一点收下这段：……`
  - `用一点回看一条`

## 设计依据

- 品牌土壤：先呈现具体使用场景和真实结果，再解释功能；避免抽象自夸。
- 小红书导演规范：一页一个任务，使用真实操作画面与截图式标注，首屏先让人看懂“这有什么用”。
- 产品边界：Skill 记录回看日期，但当前不宣称系统自动推送；用户主动发出回看使用句。

## 同类产品参照

- Readwise：Daily Review 一次呈现一条旧高亮，并让用户继续保留、丢弃或调整。
- mymind：Serendipity 重新浮现被忘记的收藏。
- Raindrop.io：对单条收藏设置明确时间提醒。

一点的差异：不只把旧内容带回来，还把“当时的判断”带回来，并邀请用户做一个当下决定。
