# Final

## Skill 展示信息
名称：一点｜重要内容回看
简介：把工作和学习中值得再见的内容收下，再带回三次，重新理解、判断并行动。
建议场景：学习效率、知识管理、工作复盘（以后台可选标签为准）

## 用户真正怎么用
1. 在笔记底部点击“一点｜重要内容回看”。
2. 点击“去使用”，复制安装口令。
3. 把口令发给自己的 AI 助手。
4. 安装后说：“用一点收下这段”，并粘贴文字、链接或资料。
5. 立刻收到“已收下 · 还有 3 次回看”记录卡。
6. 同意保存后，记录进入当前目录的《一点记录.md》。
7. 以后说“用一点回看一条”，一次只带回一条。

## 第一篇挂载笔记
封面：收藏了很多，真正回来看的有几条？

内容顺序：
1. 收藏后的真实困境。
2. 输入示例：“用一点收下这段。”
3. 即时结果：已收下记录卡。
4. 回看示例：又见面了，第 1 次回看。
5. 三个轻量选择：用上、继续留下、不再需要。
6. 使用步骤：点笔记底部组件 → 去使用 → 复制口令 → 发给 AI 助手。
7. 能力说明：RED Skill 版本在 AI 助手中使用；Edge 版负责网页自动回看。

收束句：重要的，不只见一次。

## 小红书传播路径
### 第一篇：让人认出问题并看到结果
- 标题：收藏了很多，真正回看的有几条？
- 任务：用真实收藏困境引出“一点”，展示“用一点收下这段”与“已收下 · 还有 3 次回看”。
- 行动：点击笔记下方 RED Skill 组件，复制安装口令交给自己的 AI 助手。

### 第二篇：把安装和使用讲明白
- 标题：我把“一点”做成了一个能安装的 Skill
- 任务：逐屏演示“点组件 → 去使用 → 复制口令 → 发给 AI 助手 → 收下一条”。
- 行动：让读者用一段真实工作或学习内容完成第一次测试。

### 第三篇：用真实结果建立信任
- 标题：这一条内容，回来以后真的还有用吗？
- 任务：展示一条内容从收下到第一次回看，再到“用上 / 继续留下 / 不再需要”的真实过程。
- 行动：邀请用户只反馈一个卡点，不急着建群或导流。

## 第一篇 8 页结构
1. 封面：收藏了很多，真正回看的有几条？
2. 痛点：我缺的不是收藏夹，是再见一次。
3. 输入：对 AI 助手说“用一点收下这段”。
4. 结果：已收下 · 还有 3 次回看。
5. 回看：又见面了 · 第 1 次回看。
6. 选择：用上 / 继续留下 / 不再需要。
7. 安装：笔记下方组件 → 去使用 → 复制口令 → 发给 AI 助手。
8. 收束：重要的，不只见一次。

## 发布边界
- 小红书负责发现和分发；Skill 安装后在用户自己的 AI 助手中运行。
- 这篇不放站外链接、二维码或“私信领安装包”，只使用平台内 RED Skill 组件。
- 不宣称自动提醒；宿主具备定时能力且用户明确同意后，才可以设置提醒。
- Skill 版负责用户交给 AI 的工作学习内容；Edge 版负责网页收藏自动回看。第一篇以 Skill 版为主，不同时推两个安装入口。
