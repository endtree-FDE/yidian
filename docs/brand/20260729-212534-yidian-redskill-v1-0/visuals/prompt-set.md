# 一点 RED Skill 小红书图文提示词

统一要求：3:4 竖版，奶油白、深林绿、薄荷绿、珊瑚色；圆圆软软的陪伴角色，不是蛋；现代中文无衬线字体；手机端清晰；不要蓝紫渐变、PPT 列表、二维码、外链、水印、巨大页码。

## 01 封面

展示“收藏后很少回看”的问题。文字：

- 一点 · 重要内容回看
- 收藏了很多，真正回看的有几条？
- 重要的，不只见一次

## 02 安装

用三张纵向连接的圆角卡片说明：

1. 点开笔记下方的一点 Skill
2. 点击「去使用」，复制口令
3. 把口令发给自己的 AI 助手

底部注明：小红书负责发现；安装后在 AI 助手里使用。

## 03 收下

展示对话“用一点收下这段：好的收藏，不是终点。”以及结果卡：

- 已收下 · 还有 3 次回看
- 好的收藏，不是终点
- 这次先记住：收藏的价值，在于以后还能重新判断。
- 下次回看：明天
- 先看到结果，再决定要不要保存。

## 04 回看

展示“用一点回看一条”以及回看卡：

- 又见面了 · 第 1 次回看
- 现在，它对你还有什么用？
- 用上
- 继续留下
- 不再需要
- 重要的，不只见一次。
