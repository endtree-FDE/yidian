# Directions

## 方向 A：把浏览器插件原样写成 Skill
优点：品牌统一。
问题：容易误导用户以为 Skill 也能稳定自动提醒。
结论：不选。

## 方向 B：AI 助手里的重要内容回看伙伴
用户说“用一点收下这段”，立刻得到记录卡；经用户同意后保存到可读的《一点记录.md》。用户说“用一点回看一条”，再带回一条到期内容。
优点：行为简单、结果可见、跨 Agent 更容易成立。
结论：选用。

## 方向 C：直接做站内小工具
优点：最接近普通用户。
问题：站内运行能力和接口仍在变化，现在投入代码会绑定未稳定的平台能力。
结论：暂不做，等账号真实获得站内小工具入口后再评估。

## 角色分工
- 浏览器插件：自动收藏网页、按节奏回看。
- RED Skill：把用户交给 AI 助手的工作学习内容收下和回看。
- 小红书笔记：用真实案例解释问题、展示结果、承接讨论。
