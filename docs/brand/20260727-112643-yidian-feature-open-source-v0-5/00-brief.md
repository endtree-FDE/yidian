# Brief

## 原始需求

首页没有展示“收藏”及完整现版本功能；需要补齐功能表达，并把反馈、开源维护与 Star 邀请形成一个可迁移到艺讯等项目的实践。

## 结构化 Brief

- 对象：一点 1.0.0 Chromium 浏览器扩展及公开页面
- 目标：让第一次访问者看懂当前已经能做什么，并在产生价值判断后进入下载、反馈或 Star
- 人群：在工作和学习中收藏重要网页或段落、但之后难以再次使用的人
- 交付：首页现版本功能区、收藏页视觉示意、反馈入口文案、README 开源说明
- 限制：只表达已经实现的能力；不把未来路线写成当前功能；不宣称支持任何浏览器；不制造虚假社群入口

## Brief 等级

A 级。产品事实可从扩展源码、记录页和测试核验，公开渠道与目标清楚。

## 核心判断

“展示所有功能”不等于罗列技术细节。应展示用户能感知的完整闭环：Mark、回来、宠物回应、收藏管理、本地备份与隐私边界。
