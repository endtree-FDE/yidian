# 创作方向

## 方向一：功能清单型

把全部功能排成六到八个卡片。信息完整，但容易像说明书，收藏页仍然缺乏可感知证据。

## 方向二：概念故事型

继续围绕“回来”和宠物成长讲故事。品牌感强，但会重复原首页的问题：用户仍不知道收藏、备份和记录管理是否存在。

## 方向三：产品证据型（采用）

左侧直接呈现“我的收藏”界面示意，右侧用六项能力补全闭环：

1. 整页或选段 Mark
2. 1 / 2 / 7 / 30 回来
3. 宠物陪伴与拖动
4. 收藏集中管理
5. 本地备份
6. 无需登录

## 选择依据

先让用户看见真实产品结果，再用短文案解释功能；既补全当前版本，也保持首页不成为长说明书。反馈与 Star 放在产品价值之后。

## 放弃内容

不展示并发写入、消息队列、注入恢复等后台能力；它们应由测试和安全文档证明，不是用户选择产品的主要理由。
