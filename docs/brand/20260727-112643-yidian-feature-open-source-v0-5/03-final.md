# 最终成稿

## 现版本功能区

### 1.0.0 已经能做什么

不只收藏，也看得见它怎样回来。

现版本的完整闭环：Mark、按节奏回来、在收藏页继续处理，并把所有记录留在本地。

- 整页或选段 Mark：保存标题、网址和你主动选中的文字，第一次就完成 25%。
- 1 / 2 / 7 / 30 回来：一次只带回一条到期内容，直到四次相见、进度 100%。
- 宠物陪你继续：它会巡游、可以拖动；减少动态时也会安静下来。
- 收藏集中管理：看总数、到期和完成状态，也能重新打开来源或删除记录。
- 本地备份：记录可以导出为 JSON，也能从备份合并回来。
- 无需登录：不读取未选择的正文，不把收藏记录上传到网络。

收藏页示意辅助语：

> 打开来源 · 删除记录 · 导入 / 导出备份
