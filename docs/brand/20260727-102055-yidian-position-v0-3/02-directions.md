# 一点品牌定位 v0.3｜表达方向

## 方向 A：产品结果型（推荐）

- 策略句：一点把用户在工作和学习中 Mark 的重要内容，按节奏重新带到面前。
- 语言原则：先说结果，再说明 12730 和宠物反馈；不把“收藏”硬造为品类名。
- 样稿：`重要的，不只见一次。`、`Mark 一下，以后再见。`
- 风险：总主张在首次认知场景中需要搭配一句产品解释。
- 推荐理由：直接命中产品补上的缺口，不绑定网页，也没有越过当前事实。

## 方向 B：用户态度型

- 策略句：值得在意的内容，不该在第一次相遇后失去下文。
- 语言原则：温和表达珍惜感，不制造收藏焦虑。
- 样稿：`别让重要的，只路过一次。`、`你在意过的，值得再见。`
- 风险：容易成为阅读或内容平台都能使用的泛文案。
- 结论：用于品牌内容和海报，不承担第一层定位。

## 方向 C：工作学习场景型

- 策略句：一点让工作中的线索有后续，让学习中的内容被再次理解。
- 语言原则：用“继续、判断、回忆、核对”表现两类回来动作。
- 样稿：`工作有回音，学习有下文。`、`工作里继续，学习里再懂一点。`
- 风险：不能独立解释 Mark 和 12730。
- 结论：用于功能分区和系列传播，不承担总定位。

## 最终取舍

方向 A 作为品牌地基；方向 B 提供情绪内容；方向 C 负责工作和学习的场景展开。三者分层共存，不再强迫一句话承担全部任务。
