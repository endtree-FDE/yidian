# 一点品牌定位 v0.3｜质检

## 事实

- Mark 整页或选段、第一次 25%、12730 节奏和宠物成长均有当前产品行为支撑；
- 多载体被明确标注为后续方向，没有表述为当前已实现能力；
- 没有宣称学习效果、效率提升比例或统一记忆规律。

## 原创

- 成稿由一点的产品事实和用户矛盾重新组织，没有使用四份素材中的品牌主张、活动名称和专属概念；
- 三条核心候选已在本地 431 份素材与现有项目中精确检查，没有同句命中；
- 正式注册或大规模投放前仍需另做商标与全网近似表达检索。

## 平台适配

- 一句话定义用于官网、应用商店和产品介绍；
- 核心主张用于首屏、海报和视频标题，首次认知时搭配产品解释；
- 行动句用于按钮和引导；
- 宠物语言用于操作后的回应，不承担品类定义。

## 溯源

- 实际深读 4 份材料，均在 `01-research.md` 记录路径、原始来源、使用方式和质量边界；
- 没有把搜索命中但未打开的材料写入研究来源。

## 已放弃表达

- “会回来的收藏”：结构生硬，把结果误写成收藏本身的属性；
- “住进你工作世界的成长伙伴”：没有说明产品做什么，也遗漏学习；
- “网页复习宠物”：锁死载体和使用场景；
- “成长伙伴”：保留为体验感受，不作为产品定义。

## 下一轮验证

1. 陌生用户能否说出“它会把 Mark 的内容重新带回来”；
2. 用户是否自然把它用于工作和学习，而不是只理解为稍后读；
3. 总主张与行动句哪一句更容易被记住；
4. 正式公开投放前完成商标与全网近似表达检查。
