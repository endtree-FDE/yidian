# Brief

## 原始问题

普通用户是否理解“Chromium”和“Mark”；一点究竟面向谁；Star 邀请是否适合官网。

## 结构化 Brief

- 对象：一点 1.0.0 浏览器扩展、公开首页、扩展内界面与 GitHub README
- 目标：让第一次访问、并不熟悉开发术语的人立即看懂产品动作与当前支持范围
- 人群：在浏览器中处理工作资料、学习文章和项目上下文，收藏后常常不再打开的人
- 场景：第一次访问首页、安装扩展、第一次唤出宠物、查看收藏和进入开源仓库
- 必须保留：工作与学习、收藏会按节奏回来、25% 即时反馈、宠物成长、本地隐私
- 必须避免：把 Chromium、Mark 当作默认常识；把 GitHub Star 当作主要产品价值

Brief 等级：A。现有产品事实和用户提出的理解障碍足以直接审查。
