# 最终成稿

## 核心人群

一点首先面向：在电脑浏览器里工作和学习、遇到重要资料会收藏，却很少主动回去看的人。

## 首屏

在工作和学习中看到值得再见的网页或一段文字，先收下。一点会按节奏重新把它带到你面前；当前支持 Chrome 和 Edge 电脑浏览器。

主按钮：`收下一条`

辅助说明：`Chrome / Edge 电脑浏览器 · 无需登录 · 数据只在本地`

## 核心动作

- 首次动作：`先收下`
- 功能名称：`收下整页或选段`
- 宠物回应：`你收下，它记住；内容回来，它和你一起长一点。`
- 页脚：`先收下，以后再见。`

## 开源邀请

官网按钮：`查看源码 · 在 GitHub 支持一点`

README：`如果一点确实帮你把一份重要内容重新带回了工作或学习，欢迎给这个开源项目一个 Star。它会帮助更多人看见这个还很小的项目。`

## 技术词边界

- 首页、联系页、扩展界面：不用 Chromium，不把 Mark 当动作
- README 技术段落与开发文档：可在确有必要时使用 Manifest V3、Chromium 等精确术语
