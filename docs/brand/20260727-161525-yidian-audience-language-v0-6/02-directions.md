# 创作方向

## 方向一：保留技术词并加解释

- 示例：支持 Chrome、Edge 等基于 Chromium 的浏览器
- 优点：技术上较精确
- 风险：把用户注意力带向无助于安装和理解的概念
- 结论：不用于首页；只留在开发文档

## 方向二：把 Mark 定义成品牌动作

- 示例：Mark，也就是先把内容收下
- 优点：延续已有表达
- 风险：用户在理解产品之前先学习一个新词
- 结论：放弃，现阶段品牌没有足够认知资产支撑该词

## 方向三：直接说用户动作（推荐）

- 统一动作：收下 / 收藏
- 支持范围：Chrome 和 Edge 电脑浏览器
- GitHub 行动：查看源码 · 在 GitHub 支持一点
- 依据：用已有认知完成第一次理解，把技术名词留给真正需要它的人
