# 一点命名决策 v0.8

## 结论

保留「一点」，但不再让裸名独自承担正式产品名。

## 推荐品牌架构

| 层级 | 名称 |
|---|---|
| 用户口语／视觉主标 | 一点 |
| 正式产品名 | 一点回访 |
| 品类说明 | 工作与学习的内容回访伙伴 |
| 产品方法 | 12730 回访法 |
| 品牌主张 | 重要的，不只见一次 |

## 对外使用

- 官网标题：`一点回访 · 重要的，不只见一次`
- 浏览器商店：`一点回访｜把重要内容带回来`
- 扩展内：继续只写 `一点`
- 一句话介绍：`一点把你在工作和学习中收藏的重要内容，按节奏重新带回来。`

## 暂不使用

- `12730 文档回访伙伴`：太长，且要求用户先理解数字。
- `一点 · 文档回访伙伴`：仍偏长，并把未来限制在文档。
- 裸名 `一点` 直接上架：搜索与同类区隔不足。

## 发布前必做

1. 登录国家知识产权局商标查询系统，重点检索第 9 类与第 42 类中的「一点」「一点回访」及近似文字；若未来做课程或内容服务，再评估第 41 类。
2. 同步检查浏览器商店、应用商店、域名和主要社交账号。
3. 在查清前先以 `一点回访（测试版）` 小范围使用，不批量制作付费周边。
