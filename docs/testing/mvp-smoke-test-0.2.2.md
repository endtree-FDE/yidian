## 加载与主流程

- [ ] 开发者模式下选择 `extension` 目录，扩展成功加载且无 manifest 错误。
- [ ] 在 example.com 打开普通 HTTPS 页面，点击工具栏图标，网页悬浮宠物出现且页面中只有一个实例。
- [ ] 在带有全局 `div { opacity:.8; margin:64px; padding:20px }` 的本地测试页中，宠物完全位于视口内且 opacity 为 1。
- [ ] 在使用 `history.pushState` 切换路径和标题的 SPA 测试页中，宠物仍位于视口内，Mark 使用最新标题和 URL。
- [ ] 宠物卡片正确显示当前页面标题、URL 来源，且没有正文内容；点击后卡片也完全位于视口内。
- [ ] 在 `chrome://` 受保护页面点击图标，当前标签显示红色“!” badge，标题为“请在普通网页中使用 12730”。

## 12730 回访流程

为避免等待 30 天，可在扩展 Service Worker 的 DevTools 中，仅用于测试地修改 `chrome.storage.local` 的 `nextReviewAt` 为过去时间，然后重新点击工具栏图标；不要改生产代码。

- [ ] 到期后工具栏只显示圆点，不显示积压数字，也不为到期记录创建一秒循环 alarm。
- [ ] 点击工具栏优先展示最早到期的一份。
- [ ] 快捷键始终展示当前页面 Mark，不切换到到期回访。
- [ ] 点击“打开原文”只打开 http/https 原 URL。
- [ ] 点击“这次看完了”，阶段依次为 50%、75%、100%。
- [ ] 每次延迟完成后，下一次日期从实际完成时刻重新计算。
- [ ] 快速双击只推进一个阶段。
- [ ] 100% 后不再创建下一次提醒。
- [ ] 点击“删除记录”后，该条本地数据消失。

## 并发、交互与可访问性

- [ ] 两个窗口同时 Mark 不同文档，最终两条记录都保留。

- [ ] 键盘可聚焦宠物并操作所有按钮。
