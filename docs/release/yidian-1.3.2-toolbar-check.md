# 一点 1.3.2 工具栏验收

这一步验证正式 ZIP 的**原始权限**能在普通网页唤出宠物卡片。自动浏览器测试曾为本地测试页临时加权限，因此不能代替这次点击。

## 准备

1. 在 Edge 新建一个**不登录的本地测试配置**。不要把测试版加载到已有收藏的浏览器配置，也不要卸载旧版“一点”。
2. 把 `studio/yidian-1.3.2.zip` **先解压**到新文件夹。确认文件夹根目录直接有 `manifest.json`，其中版本为 `1.3.2`。
3. 在测试配置中打开 `edge://extensions`，开启开发者模式，选择“加载解压缩的扩展”。弹出的窗口只显示文件夹，ZIP 文件不会出现；选择上一步内含 `manifest.json` 的文件夹。确认扩展卡片显示“一点”与版本 `1.3.2`。

待测 ZIP 的 SHA256：`5062d826d139f0c7d56ea97a9d0d2267a3eded90f9fd5cf8ba0ccbecceb71f20`。

## 点击与判断

1. 打开一张不含个人资料的普通网页。不要在 `edge://`、扩展商店或新标签页上测试。
2. 从工具栏的扩展菜单找到“一点”；如有需要先固定图标，然后**点击“一点”图标**。
3. 应看到网页上的小宠物与打开的收藏卡片，卡片有“替我收好”，没有棕色 `!` 角标或英文报错。
4. 点击“替我收好”，再打开“我的收藏”。应看到这条网页，进度 `1/4`，下次回看时间已显示。

记录三件事即可：扩展卡片的版本、点击图标后是否出现卡片、收藏库是否为 `1/4`。如需截图，请选用公开测试网页，不要包含私人网址或选段。

如果没出现卡片，保留测试配置与解压文件夹，在 `edge://extensions` 找到这一份“一点”的“错误”入口，记下错误原文；不要靠卸载旧版或换安装目录来凑通过。
