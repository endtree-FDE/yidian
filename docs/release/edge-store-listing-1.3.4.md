## 本次更新说明

一点现在会在“我的收藏”先带回一条到期内容。看过后可以选择“用上了”“稍后再看”或“不再需要”，分别推进回看、推到 24 小时后或收入可恢复的归档。新增收藏库搜索、统计、免打扰、可选到期通知、侧边栏和 Markdown 导出。修复旧记录异常导致收藏库打不开、从浏览器边栏直接打开时误判当前网页，以及解压版升级后记录分离等问题。旧商店版收藏继续保存在浏览器本地，更新后应保持原扩展 ID 和数据。

## 商店详细说明

一点帮你把工作与学习中主动收下的网页或选段，在第 2、7、30 天重新带回眼前。点击浏览器工具栏图标，可以收下当前普通网页；先选中一段文字，它也会和来源一起保存。

每条收藏从 1/4 开始，随后再回看三次。到期时，“我的收藏”先展示最早该见的一条和当初选中的文字。看过后，你可以记下“用上了”、选择“稍后再看”，或把不再需要的内容放进可恢复的归档。

收藏库提供搜索、相见足迹、温和统计及 JSON / Markdown 导出。侧边栏显示当前网页的收藏状态。到期系统通知默认关闭，可以自行打开并设置免打扰时段。

一点无需登录，不接入广告或行为分析。收藏的标题、网址、主动选中的文字、时间和进度只保存在浏览器本地；未选中的网页正文不会被保存，也不会把收藏发送给开发者或第三方。

## 隐私表单

- 隐私政策 URL：`https://endtree26-yidian.ms.show/privacy.html`。
- 单一用途：帮助用户把主动收藏的工作与学习网页或选段按节奏带回，并在浏览器本地记录回看进度和处理结果。
- `activeTab`：只在用户唤出扩展时读取当前网页标题、网址和主动选中的文字，用于收藏或显示当前页状态。
- `scripting`：仅在用户主动点击图标或快捷键时，注入扩展包内的宠物卡片及样式；不注入远程代码。
- `alarms`：到期时唤醒后台，更新待回看数量和可选通知。
- `notifications`：只有用户在收藏库主动开启后，才发送系统到期通知；默认关闭，可设置免打扰。
- `sidePanel`：在用户打开侧边栏时显示当前网页的收藏状态和操作。
- `storage`：在浏览器本地保存收藏、选段、回看足迹、设置及短期侧边栏上下文。
- `unlimitedStorage`：允许较多本地收藏、选段及备份留在设备上，避免因默认配额使写入失败；不增加联网访问。
- 远程代码：否。所有 JS 和字体都在提交 ZIP 中。
- 数据类别：网页活动（主动收藏的网址、标题、时间）和网站内容（用户主动选中的文字）。不收集账户身份、付款、健康、位置或认证信息；不出售、不用于广告或信用评估。

## 审核测试说明

1. 在普通 `https://` 网页点击工具栏的一点图标，宠物卡片会出现。点击“替我收好”，在“我的收藏”看到进度 1/4 和下次回看时间。
2. “我的收藏”可搜索、打开原网页、导出 JSON / Markdown；侧边栏可从浏览器边栏直接打开，显示当前页状态。
3. 首次回看在收下约 24 小时后到期。要立即验证，可从 `https://endtree26-yidian.ms.show/edge-review-sample.json` 下载无个人数据的示例备份，在“我的收藏”→“备份”中导入。顶部的“今天看一条”会立即出现，并提供“用上了／稍后再看／不再需要”。后两者分别推迟一天或收入可恢复归档。
4. 到期通知默认关闭；在收藏库的“提醒设置”中可以开启通知并调整免打扰。
5. `edge://`、扩展商店和新标签页不允许注入；在普通网页使用即可。扩展不要求登录、不上传收藏数据。
