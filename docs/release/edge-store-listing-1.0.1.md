## 本次更新说明（可直接粘贴）

说清楚“1/4”代表什么：每条内容共 4 步，收下 1 次，再回看 3 次。首次打开、收下后的状态、收藏页与浏览器按钮提示现在使用同一套语言。本次不改变回看节奏和本地数据结构，已有收藏会继续保留。

## 商店详细说明（可直接粘贴）

一点是一款给工作与学习使用的收藏回看工具。看到值得继续处理的网页、资料或文章时，点击浏览器工具栏中的“一点”，即可保存当前网页；如果先选中一段文字，它也会和来源一起留下。

收藏不是终点。一点会在第 2、7、30 天把内容重新带回眼前，并用图标旁的数字安静显示待回看的数量。你主动点击时，它一次只带回一条；每条内容共 4 步：收下 1 次，再回看 3 次。收下后显示“进度 1/4”，以后每完成一次回看，进度继续推进，宠物也随之成长。

“我的收藏”页面可以查看全部记录、下次回看时间和四步进度，也能打开原网页、修改失效链接、删除单条记录，并通过 JSON 导入或导出本地备份。

一点不要求注册账号，不接入广告或行为分析。网页标题、网址、回看进度和你主动选中的文字只保存在浏览器本地，不会上传给作者或第三方。它只在你点击图标或使用快捷键时出现在当前普通网页，不会常驻读取所有网页内容。

适合想把收藏真正用起来的学生、研究者、创作者和项目工作者。重要的，不只见一次。

## Privacy 页面填写稿

### Single Purpose Description

帮助用户把工作和学习中主动收藏的网页或选段，在第 2、7、30 天重新带回眼前，并在浏览器本地记录“收下 1 次、回看 3 次”的四步进度。

### Permission justification

- activeTab：只在用户点击扩展图标或使用快捷键时，读取当前标签页的标题、网址和用户主动选中的文字，用于创建收藏或展示回看卡片。
- scripting：只在用户主动操作后，将扩展包内的宠物界面和样式注入当前普通网页；不使用常驻内容脚本，也不申请全站访问权限。
- alarms：按收藏记录的下次回看时间唤醒扩展，检查第 2、7、30 天的到期状态。
- storage：在浏览器本地保存收藏记录、回看进度和显示设置，并支持本地 JSON 备份与恢复。

### Remote code

选择：No, I am not using remote code.

扩展为 Manifest V3，所有运行代码均包含在提交的 ZIP 包中；不加载远程脚本、远程模块或动态执行代码。

### Data usage

按表单的实际提问如实选择：

- 如果问题是“是否访问、收集或传输个人信息”：选择“是”，因为扩展会在用户主动操作时访问当前网页网址、标题和选中文字。
- 数据类型选择与“网站内容 / 浏览历史或网页活动 / 用户提供的内容”最接近的项目；不要选择身份、位置、财务、健康、通信或认证信息。
- 明确说明：这些内容仅在用户设备本地处理和保存，不传输给开发者或第三方，不用于广告、分析、画像、出售或信用评估。
- 勾选限制使用、非出售、非广告等声明前，逐项确认其文字与上述事实一致。

## Notes for certification（可直接粘贴）

一点无需登录，也不依赖外部服务。

测试步骤：
1. 在任意普通 http:// 或 https:// 网页点击工具栏中的“一点”图标，扩展会在页面右下角显示宠物和收藏卡片。
2. 未收藏页面会直接说明“共 4 步：收下 1 次，再回看 3 次”。点击“收下这条”后，记录保存在浏览器本地，并显示“进度 1/4”和第一次回看时间。
3. 点击卡片中的“我的收藏”，可查看记录、打开原网页、修改链接、删除记录或导入导出 JSON 备份。
4. 为便于立刻验证回看流程，可导入一份 nextReviewAt 已到期的合法备份；再次点击工具栏图标会显示待回看内容，点击“完成这次回看”后进度推进一级。
5. edge://、扩展商店、新标签页等受保护页面不允许脚本注入。此时图标显示琥珀色 !，切换到普通网页即可恢复。
6. 到期数量在图标旁以绿色数字显示；扩展不发送系统通知，不强制打断用户。

权限仅为 activeTab、scripting、alarms、storage，没有 host_permissions 或常驻 content_scripts。所有代码包含在提交包中，不使用远程代码。收藏数据不上传。
