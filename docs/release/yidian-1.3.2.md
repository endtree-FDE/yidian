# 一点 1.3.2 发布核对

## 本次修复

- 异常旧记录不再让正常收藏和回看失效。无法识别的原始条目先保存在浏览器本地，JSON 备份会带上它们；备份重新导入也会保留这些条目。
- 归档、恢复、删除和导入涉及收藏库及归档时，合为一次本地写入，避免第二步失败后只改动一边。
- 官网与收藏库说明解压版应在原安装文件夹更新；从新文件夹再次加载会形成另一份扩展，收藏与快捷键不会自动合并。
- 侧边栏去掉无操作作用的大面积宠物图案，当前页状态、操作和四步进度更清楚；后台断连时，侧边栏与收藏库提供中文恢复提示和重试入口。
- `core/`、`extension/`、官网版本、PWA 缓存和安装 ZIP 统一为 1.3.2。发布脚本在测试后逐文件构建 ZIP，并校验条目路径及内容哈希。

## 已验收

- `npm run check`：111 项通过。
- `npm run test:e2e`：真实 Edge 中，从线上 1.3.1 包沿原目录升级到 1.3.2，扩展 ID 与收藏保留；第二目录产生独立 ID、独立存储及快捷键冲突；官网四步演示可操作；临时测试权限下的真实宠物注入、收藏、窄侧栏进度和收藏库断连恢复提示通过。测试权限不进入发布包。
- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/release.ps1`：以上检查通过并生成 `studio/yidian-1.3.2.zip`。
- 独立读取 ZIP：23 个条目，均为便携的 `/` 目录路径，内容 SHA256 与 `extension/` 逐文件一致，根目录 `manifest.json` 为 1.3.2。同一源码连续打包两次，ZIP SHA256 相同。

## 发布顺序

1. 审查并合并 GitHub 源码变更，确认主分支包含 1.3.2 的扩展、官网源码及 ZIP。
2. 从同一次提交的 `studio/` 同步到 ModelScope 创空间的 `master`，保留其 Git 历史，采用正常快进提交，不强推。
3. 打开公开页面核对版本与安装链接；下载 ZIP 回读清单版本及文件哈希；在 Edge 的固定安装目录完成一次真实升级、唤出宠物、收藏、回看和备份导入。
4. 仅在这些检查通过后对外宣布 1.3.2。已有多个解压版的用户应先逐份导出备份、再合入保留的版本，核对完成前不要卸载旧版。
