# 一点 1.3.4 发布核对

## 这次交付

- “我的收藏”顶部只突出最早到期的一条，展示标题、来源、选段、进度和原网页入口；其余记录仍能搜索和查看。
- “用上了”只推进一次到期回看；“稍后再看”把它推到 24 小时后，进度不变；“不再需要”收入可恢复的归档，不再参与提醒。网页宠物、侧边栏和收藏库使用相同的处理结果。
- 处理结果进入相见足迹及 JSON / Markdown 导出。旧记录和旧备份不需要迁移；较旧备份不会把后来归档的内容重新变成待回看。
- 处理一条到期内容时会清除之前发出的提醒，避免系统通知仍指向旧状态。
- 从浏览器边栏直接打开侧边栏时读取活动网页；标签网址暂不可见时从已唤出的宠物读取，导航后清除旧页上下文。工具栏和快捷键入口也会保存当前页信息；实在读不到时明确提示点击工具栏连接。
- 官网、扩展、安装包和离线缓存统一为 1.3.4；扩展权限不增加。
