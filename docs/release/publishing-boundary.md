# 一点发布边界

## 硬性规则

一点只允许发布到终树本人拥有、由终树本人创建、与其他个人或组织没有权限关系的空间。

## 当前允许目标

- GitHub 个人仓库：`2487238628/yidian`
- GitHub Pages：`2487238628.github.io/yidian`
- ModelScope 个人创空间：`endTree26/yidian`

## 禁止目标

- 组织或团队仓库
- 共享项目、共同所有的空间
- 他人账号下的仓库或站点
- 无法明确确认所有者的发布目标

## 每次发布前检查

1. 核对网址和仓库 owner 与上面的允许列表完全一致。
2. 核对仓库、Pages 或创空间由终树本人创建并控制。
3. 如出现组织、团队或其他成员权限关系，立即停止发布并由终树确认。
4. 只向已核对的目标推送，不把令牌、密码或登录状态迁移到其他空间。
